# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de aproximadamente 1 hora introduce a estudiantes de secundaria a los fundamentos de programación con Java. El curso está diseñado para principiantes absolutos y no requiere instalar ningún programa. Solo se necesita abrir un navegador web y usar un editor online de Java.

Durante el curso, el estudiante aprenderá conceptos básicos como impresión en consola, variables, operadores, condicionales, bucles, métodos, entrada de datos con `Scanner`, clases, objetos, constructores y encapsulación. Al finalizar, podrá construir un programa sencillo de registro de estudiantes aplicando programación orientada a objetos básica.

**Duración total:** ~60 minutos  
**Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa en programación  
**Prerrequisitos:** Ninguno  
**Herramientas necesarias:** Solo navegador web (Chrome, Firefox, Safari o Edge)  
**Editor online sugerido:** OnlineGDB Java Compiler

## Secuencia de la Lección

### Lección 1: ¿Qué es programar y qué es Java? (6 minutos)

**Descripción:**  
En esta primera lección, el estudiante comprenderá qué significa programar, qué es Java y cómo se ejecuta un programa básico. Se mostrará el clásico ejemplo de impresión en consola para perder el miedo al código.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Programar es dar instrucciones a una computadora. Java permite escribir programas usando una estructura clara. `System.out.println()` sirve para mostrar mensajes en consola.

**Práctica:**  
Abrir el archivo inicial de la lección y completar mensajes simples en consola.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 2: Variables y tipos de datos (6 minutos)

**Descripción:**  
El estudiante aprenderá a guardar información usando variables. Se usarán datos simples de un estudiante, como nombre, edad, promedio y estado activo.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Una variable es como una caja donde se guarda un dato. `String` guarda texto, `int` guarda números enteros, `double` guarda números decimales y `boolean` guarda valores verdadero o falso.

**Práctica:**  
Crear variables con datos de un estudiante e imprimirlas en consola.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 3: Operadores y expresiones (6 minutos)

**Descripción:**  
El estudiante aprenderá a realizar operaciones matemáticas básicas en Java. Se calculará el promedio de un estudiante usando tres notas.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Los operadores permiten realizar cálculos. Se usarán suma, resta, multiplicación y división. Una expresión combina valores y operadores para producir un resultado.

**Práctica:**  
Cambiar las notas de un estudiante y calcular un nuevo promedio.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 4: Condicionales if-else (6 minutos)

**Descripción:**  
El estudiante aprenderá a hacer que un programa tome decisiones. Se evaluará si un estudiante aprobó o necesita practicar más según su promedio.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
`if` permite ejecutar código si una condición se cumple. `else` permite responder cuando la condición no se cumple. Las condiciones ayudan a que el programa tenga respuestas diferentes.

**Práctica:**  
Cambiar el promedio de un estudiante y observar cómo cambia el resultado del programa.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 5: Bucles for y while (6 minutos)

**Descripción:**  
El estudiante aprenderá a repetir instrucciones sin escribir el mismo código muchas veces. Se usarán bucles para mostrar una lista de estudiantes y una cuenta regresiva.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Un bucle repite instrucciones. `for` se usa cuando sabemos cuántas veces repetir. `while` se usa mientras una condición sea verdadera.

**Práctica:**  
Modificar el bucle para mostrar más estudiantes en consola.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 6: Métodos y parámetros (6 minutos)

**Descripción:**  
El estudiante aprenderá a organizar el código usando métodos. Se crearán métodos para mostrar información de un estudiante y verificar si aprobó.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Un método es un bloque de código que realiza una tarea. Los parámetros permiten enviar datos a un método. Los métodos ayudan a evitar repetir código.

**Práctica:**  
Crear otro estudiante y reutilizar el método para mostrar su información.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 7: Entrada de datos con Scanner (6 minutos)

**Descripción:**  
El estudiante aprenderá a ingresar datos desde la consola usando `Scanner`. El programa pedirá el nombre, la edad y el promedio de un estudiante, y luego mostrará si aprobó o necesita practicar más.

**Enlace:** [https://www.youtube.com/watch?v=fzcz8hjIvBk](https://www.youtube.com/watch?v=fzcz8hjIvBk)

**Conceptos clave:**  
`Scanner` permite leer datos escritos por el usuario. `nextLine()` lee texto, `nextInt()` lee números enteros y `nextDouble()` lee números decimales.

**Práctica:**  
Ejecutar el programa con un promedio aprobado y luego con un promedio desaprobado.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 8: Clases, objetos y constructores (6 minutos)

**Descripción:**  
El estudiante aprenderá la base de la programación orientada a objetos. Se creará una clase `Student` con atributos, constructor y un método para mostrar información.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
Una clase es como un molde. Un objeto es algo creado a partir de ese molde. Los atributos guardan datos. Los métodos representan acciones. El constructor permite crear objetos con datos iniciales.

**Práctica:**  
Crear un tercer estudiante usando la misma clase `Student`.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 9: Getters, setters y encapsulación (6 minutos)

**Descripción:**  
El estudiante aprenderá a proteger los datos de una clase usando encapsulación. Se usarán atributos privados, getters para leer datos y setters para modificar valores con control.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
La encapsulación protege los datos. `private` evita el acceso directo a los atributos. Los getters permiten leer datos y los setters permiten modificarlos con validación.

**Práctica:**  
Cambiar el promedio de un estudiante a un valor válido y luego probar con un valor inválido.

**Herramienta:** OnlineGDB Java Compiler

---

### Lección 10: Proyecto final y errores comunes (6 minutos)

**Descripción:**  
En esta última lección se integrará todo lo aprendido en un programa final de registro de estudiantes. Se crearán varios objetos, se guardarán en un array, se mostrará su información, se calculará el promedio general y se identificará al estudiante con mejor promedio.

**Enlace:** [Ver la lección](Agregar enlace de YouTube aquí)

**Conceptos clave:**  
El proyecto final combina variables, condicionales, bucles, métodos, clases, objetos, constructores, encapsulación y arrays. También se revisan errores comunes como olvidar punto y coma, cerrar mal llaves o confundir nombres de variables.

**Proyecto final:**  
Crear un registro simple de estudiantes en Java.

**Herramienta:** OnlineGDB Java Compiler

## Recomendaciones para el Estudiante

* No necesitas instalar nada.
* Usa solo el navegador web.
* Abre el editor online indicado.
* Lee los comentarios del código inicial.
* Completa los TODO paso a paso.
* Ejecuta el programa con el botón Run.
* Cambia algunos datos para practicar.
* Revisa el ejemplo completo si te quedas atascado.

---

## Consejos para Principiantes

* No te preocupes si al inicio el código parece raro.
* Lee los errores con calma.
* Revisa si olvidaste un punto y coma.
* Verifica que las llaves `{ }` estén bien cerradas.
* Recuerda que Java diferencia mayúsculas y minúsculas.
* Cambia una cosa a la vez y vuelve a ejecutar el programa.
* Practicar es más importante que memorizar.
